# 霓虹防线 · 飞机大战

一个无需安装、无需联网的本地 Canvas 飞机大战游戏。双击 `index.html` 即可在浏览器中游玩。

## 开始游玩

1. 打开本文件夹中的 `index.html`。
2. 在右侧预选“蔚蓝风暴”“银翼杀手”“青岚影忍”或“曜金流星”，再在开始弹窗点击“启动战机”。
3. 击败敌机、收集强化包，并突破四道 Boss 防线。

主界面右侧的“游戏说明”按钮会打开完整的规则与战机图鉴。它仅在准备阶段或已暂停时可用；关闭后会保持原先的准备或暂停状态。

游戏完全使用本地 HTML、CSS、JavaScript 和图片资源，不依赖服务器或第三方库。
音效由浏览器 Web Audio API 实时合成，无需下载音频文件或联网；首次点击/按键后生效，可在右侧“音效：开/关”按钮静音。

项目的后续优化路线见可离线打开的 [未来优化路线.html](未来优化路线.html)。

`fighter-catalog.js` 集中战机资料、技能规则与视觉描述；`game-rules.js` 负责通用战斗状态推进；`run-session.js` 管理准备、暂停、结束和登记流程；`game-storage.js` 统一管理浏览器本地成绩；`page-presentation.js` 统一处理 Canvas、HUD、弹窗、排行榜和触控意图。`index.html` 只负责启动会话、键盘输入与动画循环。

## 操作说明

| 动作                 | 键盘                   | 触控                   |
| -------------------- | ---------------------- | ---------------------- |

| 暂停 / 继续          | `Space`                | 点击“暂停 / 继续”      |
| 音效开关             | —                      | 点击右侧“音效：开/关”  |
| 充能技               | `Q`                    | 点击右侧对应的技能按钮 |
| 普通技               | `E`                    | 点击右侧对应的技能按钮 |
| 潮涌屏障（蔚蓝风暴） | `E`                    | 点击“E · 潮涌屏障”按钮 |

战机可在战场下方 60% 的区域内四方向移动，支持斜向移动；武器会自动向上持续射击。

## 游戏规则

- 初始拥有 3 点生命；敌弹或敌机碰撞会造成 1 次伤害。命中后敌弹立即消失，战机获得 **1 秒**无敌闪烁保护。
- 普通敌机、快速敌机、精英敌机会随机出现；达到 300 分后，普通敌军也会开始发射敌弹。

### 普通敌军分段难度

Boss 战期间会暂停普通敌军生成与射击；击败 Boss 后按当前分数恢复对应档位。Boss 本身的血量、横移与弹幕规则不受此表影响。

| 分数区间      | 生成间隔 | 普通 / 快速 / 精英速度 | 小兵射击间隔 | 敌方子弹纵向速度 |
| ------------- | -------: | ---------------------: | -----------: | ---------------: |
| 0–9,999       |    900ms |     85 / 135 / 62 px/s |       1100ms |         205 px/s |
| 10,000–29,999 |    700ms |     95 / 155 / 68 px/s |        900ms |         235 px/s |
| 30,000–49,999 |    650ms |    102 / 167 / 74 px/s |        825ms |         250 px/s |
| 50,000 及以后 |    600ms |    110 / 180 / 80 px/s |        750ms |         260 px/s |

- 右侧可在准备阶段预选战机；开局后机体锁定，重新开始会保留当前选择。刷新页面默认选择**蔚蓝风暴**。
- 四种战机的移动速度、普通子弹伤害与生命相同。普通、快速、精英敌机被常规武器击毁后，都会分别提供 `2 / 3 / 5` 技能能量；满 100 能量且 18 秒冷却结束后可按 `Q` 释放充能技。
- **蔚蓝风暴／冲击波**：清除战机半径 300（机身宽度的 5 倍）内的普通敌机和敌方子弹（包括 Boss 子弹），但不会伤害 Boss 本体。冲击波清除的普通敌机仍按原分值计分，但不掉落强化包，也不为下一次技能充能。
- **蔚蓝风暴／潮涌屏障（E 普通技）**：不消耗充能技能量，按 E 立即获得持续 5 秒的蓝色护盾，基础冷却为 30 秒。护盾被敌弹或敌机触发后立即消失，冷却不缩短；若 5 秒自然结束且没有被触发，则将当前剩余冷却额外减少 5 秒。护盾技能与 Q 充能技冲击波独立计算。
- **银翼杀手／隐匿**：进入 3 秒隐匿无敌状态，不受敌弹与敌机碰撞伤害；命中的敌弹仍会消失。隐匿不清除敌人、不伤害 Boss，也不会停止自动射击。
- **青岚影忍／影分身援护**：在左右后方召唤两架半尺寸僚机，持续 8 秒。每次主机自动射击时，僚机各发射一发 `4 × 8.5`、伤害 `0.5` 的绿色支援弹；散射弹会让每架僚机发射三发扇形弹，双倍火力会同步缩短全部射击间隔。僚机没有独立生命，但其子弹可命中普通敌机和 Boss，击毁普通敌机照常计分并充能。
- **青岚影忍／影刃双袭（E 普通技）**：独立于 Q 充能技，不消耗能量。按 E 会召唤两道短暂绿色影分身，按距离优先突袭至多两架不同的普通、快速或精英敌机，每道造成固定 2 点伤害；场上没有三类敌机时，两道影分身会共同攻击 Boss、总共造成 4 点伤害。完全无目标时不触发也不进入冷却。影刃存在约 0.45 秒，12 秒冷却；击杀照常计分，但不掉落强化包、不增加 Q 能量，也不继承散射弹或双倍火力。它不会改变 Q 双僚机的位置、射击或剩余时间。
- **曜金流星／耀斑追猎**：释放后持续 5 秒；这段时间内新发射的金黄色子弹会平滑追踪距离自身最近的普通敌机。场上没有普通敌机时可锁定 Boss；完全没有目标时维持直线向上飞行。已发射的追踪弹会持续追击至命中或飞出战场，散射弹与双倍火力可正常叠加。
- **银翼杀手／瞬闪突袭（E 普通技）**：独立于 Q 充能技，不消耗能量。按 E 会向最近的普通、快速或精英敌机发射银白定位标记；有普通敌机时不会选择 Boss，只有场上没有普通敌机时才会锁定 Boss。标记命中目标后，目标暂时免疫主弹、散射弹、僚机子弹和冲击波伤害；普通敌机进入战机可移动区域后，5 秒内再次按 E 可瞬移到其下方并造成固定 3 点伤害。锁定 Boss 时二段造成 3 点伤害但不会传送到 Boss。二段完成后进入 15 秒冷却；没有目标时不生成标记，也不消耗冷却。二段击杀不掉落强化包、不增加技能能量。
- **曜金流星／星煌跃迁（E 普通技）**：独立于 Q 充能技，不消耗能量。按 E 在战机机头当前位置放置一个持续 5 秒的金色空间标记；再次按 E 会将战机传送到标记位置，不锁定敌机、不造成伤害。二段完成后进入 10 秒冷却并获得 0.3 秒无敌；标记自然过期同样进入 10 秒冷却。该技能不影响敌机、敌弹和 Boss。
- 击毁敌机有合计 10% 概率掉落强化包：护盾 2.5%、散射弹 3%、双倍火力 3.5%、治疗药水 1%。
- 强化效果均持续 8 秒：
  - **护盾**：抵挡一次命中后消失。
  - **散射弹**：每次自动射击发射三发扇形子弹。
  - **双倍火力**：射击间隔从 180ms 缩短为 90ms；可与散射弹叠加。
  - **治疗药水**：立即恢复 1 格生命；满血时拾取仍会消耗，但不会产生效果。

## Boss 与通关

首次达到下列分数时，会清空普通敌军并进入 Boss 战：

| 分数    | Boss 防线 |
| ------- | --------- |
| 10,000  | 第一防线  |
| 30,000  | 第二防线  |
| 50,000  | 第三防线  |
| 100,000 | 最终防线  |

Boss 会在战场上方横移，并交替使用扇形与三连弹幕。击败 100,000 分最终 Boss 后通关。

## 计分与排行榜

- 右侧显示本局得分、最高分、生命、战斗用时、强化状态以及当前战机的技能能量/冷却状态。
- 战斗用时只累计实际游戏时间；暂停不计时。
- 击败 10,000 分第一道 Boss 后获得上榜资格；本局死亡或最终通关结束时输入 Player ID，即可登记成绩。
- 排行榜优先按分数从高到低排序；分数相同则按用时从短到长排序，保留前 10 条记录；同一 ID 可保存多次成绩。
- 最高分与排行榜仅保存在当前浏览器设备中；清除浏览器站点数据后会一并清空。

## 本地数据键

- `aircraft-battle-high-score-v1`：最高分。
- `aircraft-battle-clear-rank-v1`：通关排行榜。
- `aircraft-battle-sound-enabled-v1`：音效开关偏好（默认开启）。

## 开发验证

在本文件夹运行：

```bash
npm install
npm run check
```

该命令会检查格式、生产 JavaScript 语法，以及固定输入下的规则、会话、存储和呈现测试。开发依赖仅用于验证，不会影响双击 `index.html` 的离线游玩。
