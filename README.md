# 霓虹防线 · 飞机大战

一个无需安装、无需联网的本地 Canvas 飞机大战游戏。双击 `index.html` 即可在浏览器中游玩。

## 开始游玩

1. 打开本文件夹中的 `index.html`。
2. 在右侧预选“蔚蓝风暴”“银翼杀手”“青岚影忍”或“曜金流星”，再在开始弹窗点击“启动战机”。
3. 击败敌机、收集强化包，并突破四道 Boss 防线。

游戏完全使用本地 HTML、CSS、JavaScript 和图片资源，不依赖服务器或第三方库。

项目的后续优化路线见可离线打开的 [未来优化路线.html](未来优化路线.html)。

`fighter-catalog.js` 集中战机资料、技能规则与视觉描述；`game-rules.js` 负责通用战斗状态推进；`run-session.js` 管理准备、暂停、结束和登记流程；`game-storage.js` 统一管理浏览器本地成绩；`page-presentation.js` 统一处理 Canvas、HUD、弹窗、排行榜和触控意图。`index.html` 只负责启动会话、键盘输入与动画循环。

## 操作说明

| 动作        | 键盘                   | 触控                   |
| ----------- | ---------------------- | ---------------------- |
| 左移 / 右移 | `←` / `→` 或 `A` / `D` | 按住左右方向键         |
| 前进 / 后退 | `↑` / `↓` 或 `W` / `S` | 按住上下方向键         |
| 暂停 / 继续 | `Space`                | 点击“暂停 / 继续”      |
| 战机技能    | `Q`                    | 点击右侧对应的技能按钮 |

战机可在战场下方 60% 的区域内四方向移动，支持斜向移动；武器会自动向上持续射击。

## 游戏规则

- 初始拥有 3 点生命；敌弹或敌机碰撞会造成 1 次伤害。命中后敌弹立即消失，战机获得短暂无敌闪烁效果。
- 普通敌机、快速敌机、精英敌机会随机出现；达到 300 分后，普通敌军也会开始发射敌弹。
- 右侧可在准备阶段预选战机；开局后机体锁定，重新开始会保留当前选择。刷新页面默认选择**蔚蓝风暴**。
- 三种战机的移动速度、普通子弹伤害与生命相同。普通、快速、精英敌机被常规武器击毁后，都会分别提供 `2 / 3 / 5` 技能能量；满 100 能量且 18 秒冷却结束后可按 `Q` 释放技能。
- **蔚蓝风暴／冲击波**：清除战机半径 300（机身宽度的 5 倍）内的普通敌机和敌方子弹（包括 Boss 子弹），但不会伤害 Boss 本体。冲击波清除的普通敌机仍按原分值计分，但不掉落强化包，也不为下一次技能充能。
- **银翼杀手／隐匿**：进入 3 秒隐匿无敌状态，不受敌弹与敌机碰撞伤害；命中的敌弹仍会消失。隐匿不清除敌人、不伤害 Boss，也不会停止自动射击。
- **青岚影忍／影分身援护**：在左右后方召唤两架半尺寸僚机，持续 8 秒。每次主机自动射击时，僚机各发射一发 `4 × 8.5`、伤害 `0.5` 的绿色支援弹；散射弹会让每架僚机发射三发扇形弹，双倍火力会同步缩短全部射击间隔。僚机没有独立生命，但其子弹可命中普通敌机和 Boss，击毁普通敌机照常计分并充能。
- **曜金流星／耀斑追猎**：释放后持续 5 秒；这段时间内新发射的金黄色子弹会平滑追踪距离自身最近的普通敌机。场上没有普通敌机时可锁定 Boss；完全没有目标时维持直线向上飞行。已发射的追踪弹会持续追击至命中或飞出战场，散射弹与双倍火力可正常叠加。
- 击毁敌机有合计 10% 概率掉落强化包：护盾 2.5%、散射弹 3%、双倍火力 3.5%、治疗药水 1%。
- 强化效果均持续 8 秒：
  - **护盾**：抵挡一次命中后消失。
  - **散射弹**：每次自动射击发射三发扇形子弹。
  - **双倍火力**：射击间隔从 180ms 缩短为 90ms；可与散射弹叠加。
  - **治疗药水**：立即恢复 1 格生命；满血时拾取仍会消耗，但不会产生效果。

## Boss 与通关

首次达到下列分数时，会清空普通敌军并进入 Boss 战：

| 分数    | Boss 防线 |
| ------- | --------- |
| 10,000  | 第一防线  |
| 30,000  | 第二防线  |
| 50,000  | 第三防线  |
| 100,000 | 最终防线  |

Boss 会在战场上方横移，并交替使用扇形与三连弹幕。击败 100,000 分最终 Boss 后通关。

## 计分与排行榜

- 右侧显示本局得分、最高分、生命、战斗用时、强化状态以及当前战机的技能能量/冷却状态。
- 战斗用时只累计实际游戏时间；暂停不计时。
- 击败 10,000 分第一道 Boss 后获得上榜资格；本局死亡或最终通关结束时输入 Player ID，即可登记成绩。
- 排行榜优先按分数从高到低排序；分数相同则按用时从短到长排序，保留前 10 条记录；同一 ID 可保存多次成绩。
- 最高分与排行榜仅保存在当前浏览器设备中；清除浏览器站点数据后会一并清空。

## 本地数据键

- `aircraft-battle-high-score-v1`：最高分。

## 开发验证

在本文件夹运行：

```bash
npm install
npm run check
```

该命令会检查格式、生产 JavaScript 语法，以及固定输入下的规则、会话、存储和呈现测试。开发依赖仅用于验证，不会影响双击 `index.html` 的离线游玩。
