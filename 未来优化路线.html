P0 · 当前执行

工程健康与质量门禁

  • 格式化源代码，维持游戏规则、战机能力与本地存档不变。
  • 建立 npm run check：格式、语法、规则测试与真实 Chromium 回归。
  • GitHub Actions 在推送与 Pull Request 时执行检查；失败时保存浏览器诊断截图。
  • 保留两支成片 MP4，取消可再生成 QA 截图的版本追踪。
P1

战斗时间线

在既有 GameRules.create/step Interface 内部深化战斗时间线 Module，集中移动、AI、碰撞、掉落与技能结算顺序。

P2

Boss 战役章节化

为四道防线增加进场、攻击前摇、阶段转换、专属弹幕与结算演出，让压力清晰且可学习。

P3

平衡与重复游玩

将敌机权重、Boss 参数和道具概率配置化，补充固定种子挑战与本地匿名对局摘要。

P4

产品体验

增加新手教学、Boss 攻击图例、移动端安全区、低特效与色弱辅助，并评估 PWA 安装能力。

P5

共享排行榜（独立项目）

如需跨设备互通，采用 Cloudflare Workers + D1 作为成绩存储 Adapter，并引入昵称、限流与客户端成绩校验；当前 localStorage 榜单继续保留。
